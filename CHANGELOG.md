# Changelog

All notable changes to **Lodestar** are recorded here. From the next release on,
this file is updated automatically from [Conventional Commits](https://www.conventionalcommits.org/)
whenever a version is published.

## 1.0.0 (2026-07-12)

First public release.

* 1–70 leveling guides for Alliance & Horde, auto-loaded by level and zone.
* On-screen waypoint arrow, minimap ant-trail and world-map pins; travel planner.
* Quest automation: auto-accept / turn-in / reward / share, plus never-stuck auto-skip.
* XP/hour pace HUD, talent suggestions, gear advisor, target markers, and a shareable report card.
* Multiple guides open at once as tabs, plus a live dungeon **run-counter**.
* **Raid Ready — Boosted 60–70**: a dungeon-spam route to level 70 with the full Karazhan attunement.
